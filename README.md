# Chemical Inventory — HS Science

This repository contains the **Chemical Inventory** section only, separated from the other HS Science inventory categories.

## Files
- `index.html` — responsive webpage, search, filters, and table rendering.
- `inventory-data.js` — records from the Chemical Inventory worksheet, including Excel hyperlinks and plain URLs.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `chemical-inventory`.
2. Upload `index.html`, `inventory-data.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the page; its URL will appear in the Pages settings.

## Notes
The page is a static copy of the worksheet at the time of export. Re-export the data if the workbook changes. Always check current labels, SDS documents, and approved safety procedures before handling or disposing of chemicals.
